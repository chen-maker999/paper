\section*{Broader Impact Statement}
This work makes long-running LLM agents cheaper and more reliable by keeping
their working state accurate under context limits. Stale or missing state can
lead agents to act on outdated information---for example to report a test as
passing after a later run failed---so methods that surface the current state,
and evaluations that measure staleness, can reduce such silent errors. More
capable autonomous agents also amplify the consequences of misuse and of
unattended mistakes; our method does not change what an agent is permitted to
do, and we recommend that compressed contexts keep provenance (as SKC's ledger
does) so that humans can audit what an agent knew when it acted. All data used
are public agent trajectories released by the SWE-bench leaderboard
participants; no human subjects were involved.
